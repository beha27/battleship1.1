# ⚔️ Морской Бой 10×10 (PvP & PvE)

Автономная веб-игра **«Морской Бой»**, созданная на чистом HTML, Tailwind CSS и JavaScript.

## 🚀 Особенности игры
- **Размер поля:** Классическое поле **10×10 клеток**.
- **Флот (по 1 кораблю каждого размера):**
  - 4-палубный (1 шт.)
  - 3-палубный (1 шт.)
  - 2-палубный (1 шт.)
  - 1-палубный (1 шт.)
- **Отображение выстрелов в PvP и PvE:**
  - `💧 Капля воды` — выстрел мимо (промах).
  - `🔥 Огонь` — ранение отдельной палубы корабля.
  - `✕ Крестик` — корабль полностью потоплен (вся его зона покрывается крестиками).
- **Синхронизация готовности (PvP):**
  - При нажатии «Готов к бою» игрок ожидает противника. Переход к бою происходит одновременно.
- **Экран конца игры:**
  - Всплывающее модальное окно при победе или поражении.
- **Игровые режимы:**
  - 🤖 **Играть против Бота** (умный PvE).
  - 🏠 **Создать комнату (PvP)** через PeerJS.
  - 🔑 **Войти в комнату (PvP)** по ID друга.

## 🛠️ Запуск проекта
1. Сохраните файлы `index.html` и `README.md` в одну папку на компьютере.
2. Дважды кликните на `index.html`, чтобы открыть игру в браузере.
